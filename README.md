- For this project I've tried to use:
    - async and await
    - try and catch
    - .then, .catch and .finally
- I've used two APIs:
    - one finds specific fields of weather data based on what is entered into the search box 
    - another takes the resulting cordinates and the original search input to confirm to the user what weather they have found
